# Security Policy

## Supported Versions

Currently, only the latest version of the extension is supported with security updates. We recommend keeping the extension automatically updated through your browser's extension store.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** report it by creating a public GitHub issue. 

Instead, please send an email directly to the maintainers or use GitHub's private vulnerability reporting feature on this repository.

All security vulnerabilities will be promptly addressed.

## Architecture & Privacy

This extension operates locally within your browser and utilizes `storage.sync` (if supported by your browser) to synchronize your Contributor ID. It does not connect to any external backend or analytics service controlled by this project. No personal data, browsing history, or page content is transmitted to our servers.
